# TrichoCMP for WordPress

Download: https://github.com/klodhi00/trichocmp-wordpress/releases/latest/download/trichocmp.zip

Release: bump `Version:` **and** `TRICHOCMP_VERSION` (and `Stable tag` in readme.txt), commit, run `./release.sh`.
The script builds `trichocmp.zip` and creates `vX.Y.Z`; sites update through the normal WordPress update screen.
