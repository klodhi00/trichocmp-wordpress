Baner zgód na cookies TrichoCMP (Consent Mode v2).

== Description ==

1. Wtyczki → Dodaj nową → Wyślij wtyczkę na serwer → trichocmp.zip → Włącz.
2. Ustawienia → TrichoCMP → wklej ID strony z panelu https://cookies.trichopartner.com (strona → Instalacja).

Wygląd, teksty, kategorie i usługi ustawia się w panelu. Wtyczka wstawia skrypt na samej górze <head>
(przed Google Tag Managerem) i wyłącza go spod optymalizacji WP Rocket, LiteSpeed, Autoptimize, SiteGround i Cloudflare Rocket Loader.

Shortcody:
* [trichocmp_preferences]Ustawienia cookies[/trichocmp_preferences] – link do ponownego otwarcia banera.
* [trichocmp_declaration] – tabela cookies do polityki cookies.

Aktualizacje przychodzą z GitHub Releases (klodhi00/trichocmp-wordpress) jako zwykłe aktualizacje WordPressa.
